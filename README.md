# ことばの辞書候補

音声入力の履歴をコピペし、辞書登録を検討する名称や、似た表記を根拠付きで確認する機械学習アプリ。
キカガク最終課題向け。Aqua Voiceとは独立した非公式の支援ツールです。

## 現在の状態

- Python内での学習済みモデル推論、Streamlit UI、選択語の編集・テキスト出力を実装。
- ローカル動作確認済み。評価・検証結果は `VALIDATION.md`。
- **GitHubへの公開、インターネットへのデプロイ、公開URLでの動作確認は未実施。課題の修了・提出完了ではありません。**
- 提出用PDFは、公開URL・GitHub URL・期・氏名と、本人の開発上の振り返りを確認してから確定します。

## ローカル起動

Python 3.12を使用します。既存の別課題の仮想環境は変更しません。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

インストール時に公開学習済みモデルとSudachiの辞書を取得します。推論に外部AI APIやAPIキーは不要です。

## 使い方

1. 架空の履歴を貼るか、「架空のサンプルで試す」を押します。
2. 任意で既存辞書の正しい表記を1行1語で入力します（最大200語）。
3. 「辞書候補を見つける」で分析します。
4. 根拠となる原文、原文一致回数、類似する表記を確認します。
5. 登録する表記を編集し、「選ぶ」→「このページの選択をリストへ追加」で確定します。
6. 選択した表記をコピー・保存し、Aqua Voice等の辞書に登録します。

テキスト出力は単語リストです。Aqua Voiceの一括インポート形式への対応や、自動設定変更は実装していません。

## モデルと補助処理

`analyzer.py:load_model` が `spacy.load('ja_ginza')` でモデルを読み込み、`analyze` の `nlp.pipe` が入力文から固有表現を推論します。ja_ginza 5.2.0は公開学習済みの日本語モデルで、独自の追加学習はしていません。

- **学習済みモデルの役割**：文脈から組織名・製品名などの固有表現を抽出する。分類結果は誤る場合があります。
- **補助ルールの役割**：形態素の固有名詞、連続する名詞、英字表記、原文一致回数、読みの類似度を使って候補を補います。
- **優先順**：NER由来30点、出現回数 `12*log2(1+回数)`、英字10点、形態素の固有名詞8点、類似表記あり20点。点数は確率ではありません。
- **類似表記**：既存辞書、または同じ履歴内で2回以上登場した語と比較します。表記の正規化、一致する読み、長さ4以上・類似度0.80以上の読みを使います。正解の自動生成はしません。
- **制限**：20,000文字、処理単位800文字、類似比較の対象160語。閾値はプロトタイプの設計値です。

公開モデルと名詞抽出・読み比較がそれぞれ何をしているかを分離して説明できる構成です。単なる外部APIの結果表示や、頻度集計だけのアプリではありません。

## 分かることと分からないこと

「自社登録」と「辞書登録」のように読みが近く、比較先の表記が既存辞書または履歴にあれば注意候補を出せます。
比較先が存在しない未知の誤りの正解や、音声を聞かないと分からない誤認識は判定できません。
短い同音語や英字・カナ間の表記は、Sudachiの読み情報によって対応できない場合があります。
入力中の頻度は、誤認識の頻度ではありません。似た読みの別語も候補になるため、ユーザーの確認が必要です。

## データ・プライバシー

同梱のサンプル・評価文は本プロジェクト用に作成した架空データです。ユーザーの実際の履歴、添付文章、個人情報・業務データは同梱していません。
公開版には個人情報や職場の業務データを入力しないでください。
入力本文のファイル保存・DB保存・ログ出力は実装していません。入力と分析結果はセッション内のメモリに残り、公開時はホスティング先に送信されます。選択した語は利用者の操作でダウンロードできます。
名前や住所を自動匿名化する機能はありません。

## 再検証

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python evaluate.py
.venv/bin/python -m pip check
```

`evaluate.py` は2件の開発文・8件の評価文を使用し、上位最大10候補の適合率と再現率、指定した類似表記ペアの検出数を記録します。
サンプルとは別の文章ですが、同じ作者の小規模な架空データで、開発文と同じ誤りパターンも含みます。実データへの汎化性能を示しません。
学習済みNERだけを無効化した比較も行います。この比較では形態素解析モデルは残るため「機械学習なし」とは呼びません。
